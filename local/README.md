This directory is ignored except for this README. Use it for private notes or
sanitization work; the installer does not deploy it. Live overrides belong in
~/.bashrc.local, ~/.tmux.conf.local, and ~/.config/nvim.local.lua.

The shared Git template is `.gitconfig.template`. Copy it to
`~/.gitconfig` and fill in your identity. Keep credentials, signing keys, and
work-specific Git settings outside the repository.
