Only intentionally sanitized historical configurations belong here. Nothing is
automatically copied here. Review a copy of a raw backup for credentials, tokens,
private paths, hostnames, email addresses, and internal work information before
staging it. Review `git diff --cached` before committing. Raw backups remain in
ignored backups/ and must never be force-added. Ignore rules do not untrack files
already committed. Keep a separate private/offline backup of important snapshots.
